# bid-change-validator-frontend

Frontend workspace for the Bid Change Validator project.

## Owners

- Main: 황수빈
- Sub: 이홍규

## Scope

- 화면설계 및 Figma 시안 반영
- UI / UX 구현
- Frontend 화면 및 사용자 흐름 구현
- Backend API 연동

## Out of Scope

- Backend 비즈니스 로직 구현
- DB 스키마 소유권
- LLM / RAG 내부 구현

## Weekend Parallel Work

이 저장소는 메인 통합 저장소에 반영하기 전 주말 병렬 작업을 위한 Frontend workspace입니다.
빠른 실험과 구현을 우선하되, 다른 영역과 맞닿는 API 계약은 메인 저장소의 공통 문서를 기준으로 정리합니다.

## Branches

- `main`: 현재 Frontend 기준선
- `develop`: 병렬 개발 통합 브랜치
- 작업 브랜치: `feat/SKN34-XX-summary`, `fix/SKN34-XX-summary`
